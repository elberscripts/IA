# Rapper Laranja — Boyfriend Skin

Mod V-Slice/Polymod para o Friday Night Funkin' oficial. Ele substitui as variantes de Boyfriend usadas nas músicas normais por Rapper Laranja.

## Instalação no Android

1. Feche totalmente o Friday Night Funkin'.
2. Extraia o arquivo `RapperLaranja-v1.0.0.zip`.
3. Copie a pasta `RapperLaranja` extraída para a pasta `mods` aberta por **Options > Open Data Folder**.
4. Abra o jogo e, se aparecer o menu de mods, habilite **Rapper Laranja — Boyfriend Skin**.
5. Reinicie o jogo se o personagem ainda não aparecer.

A estrutura correta é:

```text
mods/
└── RapperLaranja/
    ├── _polymod_meta.json
    ├── data/
    ├── images/
    └── scripts/
```

Evite deixar uma pasta duplicada como `mods/RapperLaranja/RapperLaranja/`.

## Compatibilidade

- Jogo oficial V-Slice para Android
- FNF 0.8.8
- Mod API 0.8.0

As animações de morte continuam usando o Boyfriend original, porque a imagem fornecida não inclui frames de Game Over.
